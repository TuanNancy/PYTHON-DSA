Reference 05

Queue

First In, First Out: phần tử đến trước được xử lý trước.

Python deque làm Queue

from collections import deque

queue = deque()
queue.append(value)    # enqueue ở back: O(1)
front = queue[0]       # peek front: O(1)
value = queue.popleft()# dequeue ở front: O(1)
empty = not queue      # kiểm tra rỗng

Stack và Queue

Stack: LIFO, thêm và lấy ở cùng một đầu.

Queue: FIFO, thêm ở back và lấy ở front.

Pattern nhận diện

Xử lý theo thứ tự đến: task, request, khách hàng.

Duyệt theo tầng: BFS trên tree hoặc graph.

Cửa sổ thời gian: loại dữ liệu cũ ở front.

Cẩn thận: tránh list.pop(0) vì phải dịch chuyển phần tử và có time O(n).
Nguồn: Python documentation và collections.deque.
