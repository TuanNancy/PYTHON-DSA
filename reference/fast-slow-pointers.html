Reference 08

Fast & Slow
Pointers

Hai con trỏ cùng đường đi, khác tốc độ; còn gọi là Tortoise and Hare.

Phát hiện cycle

slow = head
fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow is fast:
        return True

return False

Pattern nhận diện

Cycle: hai con trỏ gặp nhau.

Middle node: khi fast đến cuối, slow ở giữa.

Happy Number: trạng thái số lặp thành cycle.

Time O(n) Space O(1)

Cẩn thận: kiểm tra fast and fast.next trước khi truy cập fast.next.next.
Nguồn: Floyd's cycle-finding algorithm.
