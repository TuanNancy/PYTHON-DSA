Reference 04

Stack

Last In, First Out: phần tử được thêm sau cùng được lấy ra đầu tiên.

Python list làm stack

stack = []

stack.append(value)  # push: O(1) amortized
top = stack[-1]      # peek: O(1)
value = stack.pop()  # pop: O(1)
empty = not stack    # kiểm tra rỗng

Pattern nhận diện

Cặp lồng nhau: dấu ngoặc, thẻ HTML.

Hoàn tác: undo thao tác gần nhất.

Monotonic stack: phần tử lớn/nhỏ tiếp theo.

Duyệt cấu trúc: DFS không dùng đệ quy.

Cẩn thận: không gọi pop() khi stack rỗng. Kiểm tra bằng if stack hoặc if not stack trước.
