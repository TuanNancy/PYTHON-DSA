Tìm trên dữ liệu có thứ tự bằng cách loại một nửa vùng tìm kiếm mỗi bước.

Template

left = 0
right = len(numbers) - 1

while left <= right:
    mid = (left + right) // 2
    if numbers[mid] == target:
        return mid
    if numbers[mid] < target:
        left = mid + 1
    else:
        right = mid - 1

return -1

Invariant

Nếu target tồn tại, nó luôn nằm trong vùng đóng [left, right].

Time O(log n) Space O(1)

Lỗi thường gặp: sai điều kiện <=, không loại mid bằng ± 1, hoặc áp dụng trên dữ liệu chưa sắp xếp.
Nguồn: MIT 6.006 Introduction to Algorithms.
