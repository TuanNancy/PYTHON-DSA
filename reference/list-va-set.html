Reference 02

List hay Set?

Chọn theo thao tác chính mà bài toán yêu cầu, không chọn theo thói quen.

List

Dùng khi: cần giữ thứ tự, cho phép trùng, truy cập theo index hoặc duyệt tuần tự.

items = ["a", "b", "a"]
items.append("c")
second = items[1]

index O(1) append O(1) amortized membership O(n)

Set

Dùng khi: cần giá trị duy nhất, kiểm tra đã xuất hiện, loại bỏ trùng hoặc thực hiện phép toán tập hợp.

seen = {"a", "b"}
seen.add("c")
exists = "a" in seen

add O(1) average membership O(1) average không có index

Câu hỏi nhận diện: “Tôi có cần biết giá trị này đã tồn tại không?” Nếu có, hãy cân nhắc set.
