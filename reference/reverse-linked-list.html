Reference 07

Reverse
Linked List

Đảo hướng từng reference bằng ba con trỏ và không tạo thêm node.

Template

previous = None
current = head

while current:
    next_node = current.next
    current.next = previous
    previous = current
    current = next_node

return previous

Thứ tự phải nhớ

Save: giữ current.next.

Reverse: trỏ current.next về phía trước đó.

Advance: di chuyển previous và current.

Time O(n) Extra space O(1)

Invariant: trước mỗi vòng lặp, previous là head của phần đã đảo và current là head của phần chưa đảo.
