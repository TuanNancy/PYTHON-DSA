Reference 03

Dictionary

Một ánh xạ từ key duy nhất đến value: key → value.

Thao tác cơ bản

scores = {}

scores["An"] = 9          # thêm hoặc cập nhật
score = scores["An"]      # lấy value
exists = "An" in scores   # kiểm tra key
safe = scores.get("Binh") # None nếu không có key
del scores["An"]          # xóa key

Chi phí trung bình

lookup O(1) insert O(1) delete O(1) space O(n)

Pattern phỏng vấn

Đếm tần suất: value → số lần xuất hiện.

Ghi nhớ vị trí: value → index.

Nhóm dữ liệu: đặc điểm chung → danh sách phần tử.

Cache: input → kết quả đã tính.

Câu hỏi nhận diện: “Tôi cần tìm nhanh một key và lấy dữ liệu đi kèm nó không?” Nếu có, hãy cân nhắc dict.
