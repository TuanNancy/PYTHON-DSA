Singly
Linked List

Một chuỗi node; mỗi node lưu value và reference đến node tiếp theo.

Node

class Node:
    def __init__(self, value, next_node=None):
        self.value = value
        self.next = next_node

Duyệt

current = head
while current:
    use(current.value)
    current = current.next

Thêm vào đầu

new_head = Node(value, head)
head = new_head

Độ phức tạp

access O(n) search O(n) prepend O(1) remove head O(1)

Cẩn thận: luôn cập nhật current = current.next khi duyệt; nếu quên, vòng lặp sẽ không tiến lên.
