# Nền tảng Python và mục tiêu phỏng vấn

Người học đã biết cú pháp Python cơ bản gồm biến, vòng lặp, hàm và list; mục tiêu chính là chuẩn bị cho phỏng vấn lập trình. Các bài đầu có thể dùng code Python trực tiếp nhưng cần giới thiệu từng pattern DSA từ nền tảng.
