# Triển khai phát hiện trùng lặp bằng set

Người học đã tự hoàn thành hàm duyệt list một lần, kiểm tra <code>word in seen</code>, thêm từ chưa gặp và trả về Boolean đúng cho cả trường hợp có hoặc không có trùng lặp. Điều này chứng minh khả năng áp dụng set membership vào code và mở đường cho cấu trúc key-value <code>dict</code>.

## Evidence

Hàm <code>contains_duplicate</code> do người học gửi sử dụng đúng pattern <code>seen</code>, có early return và xử lý đúng trường hợp duyệt hết đầu vào.
