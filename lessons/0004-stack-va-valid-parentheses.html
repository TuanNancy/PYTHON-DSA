15 phút · Stack pattern

Stack
và dấu ngoặc

Stack xử lý dữ liệu theo quy tắc vào sau, ra trước. Nó đặc biệt phù hợp với bài toán có các cặp mở và đóng lồng nhau.

Chiến thắng của bài này: dùng list như một stack và kiểm tra chuỗi dấu ngoặc hợp lệ trong O(n).

1. LIFO: vào sau, ra trước

Hãy tưởng tượng một chồng đĩa. Đĩa đặt lên sau cùng nằm trên cùng và được lấy ra đầu tiên. Đây là Last In, First Out.

stack = []

stack.append("(")  # push
stack.append("[")  # push

top = stack.pop()  # lấy "["
print(stack)       # ["("]

Trong Python, cuối list là đỉnh stack. append() thêm vào đỉnh và pop() lấy phần tử ở đỉnh; cả hai có amortized time O(1).

2. Vì sao dấu ngoặc cần stack?

Trong chuỗi ([]), ngoặc mở gần nhất phải được đóng trước:

  1. Gặp (: push vào stack.
  2. Gặp [: push vào stack.
  3. Gặp ]: phải khớp với đỉnh [, rồi pop.
  4. Gặp ): phải khớp với đỉnh (, rồi pop.
def is_valid(text):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []

    for char in text:
        if char in "([{":
            stack.append(char)
        elif not stack or stack.pop() != pairs[char]:
            return False

    return not stack
Hai cách thất bại: ngoặc đóng không khớp với đỉnh stack, hoặc duyệt hết chuỗi nhưng stack vẫn còn ngoặc mở.

4. Hiệu năng

Mỗi ký tự được duyệt một lần và mỗi dấu ngoặc được push hoặc pop nhiều nhất một lần.

Time O(n) Space O(n)

5. Bài tập của bạn

Viết lại hàm is_valid mà không nhìn code mẫu, rồi chạy các test:

print(is_valid("()"))    # True
print(is_valid("([])"))  # True
print(is_valid("([)]"))  # False
print(is_valid("(("))    # False
print(is_valid("]"))     # False

Ghi nhớ

Khi phần tử mới nhất phải được xử lý trước, hãy nghĩ đến stack. Trong Python, ưu tiên append() và pop() ở cuối list.
