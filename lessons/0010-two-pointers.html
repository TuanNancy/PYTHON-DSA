Two Pointers
từ hai đầu

Trên sorted list, hai con trỏ ở hai đầu có thể điều chỉnh tổng theo hướng chắc chắn mà không cần thử mọi cặp.

Chiến thắng của bài này: tìm hai số có tổng bằng target trong sorted list với time O(n) và space O(1).

1. Tận dụng thứ tự

Đặt left ở số nhỏ nhất và right ở số lớn nhất:

  • Nếu tổng quá nhỏ, cần tổng lớn hơn: tăng left.
  • Nếu tổng quá lớn, cần tổng nhỏ hơn: giảm right.
  • Nếu tổng bằng target: đã tìm thấy cặp.
numbers = [1, 2, 4, 6, 10]
target = 8

1 + 10 = 11 quá lớn, nên bỏ 10. Sau đó 1 + 6 = 7 quá nhỏ, nên bỏ 1. Cuối cùng 2 + 6 = 8.

2. Code template

def two_sum_sorted(numbers, target):
    left = 0
    right = len(numbers) - 1

    while left < right:
        total = numbers[left] + numbers[right]

        if total == target:
            return [left, right]
        if total < target:
            left += 1
        else:
            right -= 1

    return []
Khác Binary Search: Binary Search dùng left <= right vì một phần tử có thể là đáp án. Two Sum dùng left < right vì cần hai index khác nhau.

4. So với Hash Map

Two Sum dùng dict ở bài 0003 hoạt động với list chưa sắp xếp nhưng cần space O(n). Two Pointers chỉ cần space O(1), đổi lại đầu vào phải được sắp xếp.

5. Bài tập của bạn

Viết hàm trả về hai index hoặc list rỗng:

numbers = [1, 3, 4, 6, 8, 11]

print(two_sum_sorted(numbers, 10))  # [2, 3]
print(two_sum_sorted(numbers, 12))  # [0, 5]
print(two_sum_sorted(numbers, 20))  # []

Gửi code cho tôi và trả lời: vì sao tổng quá nhỏ thì có thể loại phần tử tại left?

Ghi nhớ

Khi dữ liệu đã sắp xếp và cần xét cặp, hãy thử đặt hai con trỏ ở hai đầu rồi di chuyển dựa trên phép so sánh.
