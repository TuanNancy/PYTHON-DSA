Dictionary
và Two Sum

set trả lời “đã thấy chưa?”. dict đi xa hơn: “đã thấy ở đâu, và dữ liệu đi kèm là gì?”.

Chiến thắng của bài này: dùng dict để tìm hai số có tổng bằng target trong average time O(n).

1. Dictionary lưu key → value

Mỗi phần tử trong dict gồm một key và một value. Ta truy cập value bằng key thay vì bằng vị trí.

ages = {
    "An": 20,
    "Binh": 22,
}

print(ages["An"])  # 20
ages["Chi"] = 19

Trong Two Sum, ta dùng số đã gặp làm key và index của nó làm value:

seen = {2: 0, 7: 1}
#       ↑  ↑
#     number, index

Kiểm tra nhanh 1

Trong seen = {2: 0}, 2 là key. Value 0 lưu thông tin gì?

2. Ý tưởng phần bù

Ta cần hai số có tổng bằng target. Khi đang đứng ở number, số còn thiếu là:

complement = target - number

Ví dụ target là 9 và số hiện tại là 7:

9−7=2

Nếu 2 đã có trong seen, ta tìm thấy cặp 2 + 7 = 9.

def two_sum(numbers, target):
    seen = {}

    for index, number in enumerate(numbers):
        complement = target - number

        if complement in seen:
            return [seen[complement], index]

        seen[number] = index

    return []
Thứ tự quan trọng: kiểm tra complement trước rồi mới thêm number. Nhờ vậy một phần tử không bị dùng hai lần, nhưng hai số bằng nhau ở hai index khác nhau vẫn hoạt động.

4. Hiệu năng

Ta duyệt numbers một lần. Tra cứu và thêm key vào dict có average case O(1).

Time O(n) average Space O(n)

Ghi nhớ

Khi cần vừa kiểm tra một giá trị đã xuất hiện, vừa lấy thông tin gắn với nó, hãy nghĩ đến dict. Với Two Sum, thông tin đó chính là index.
