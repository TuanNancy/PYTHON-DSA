18 phút · Pointer pattern

Đảo chiều
Linked List

Để đảo chiều mà không mất phần chưa duyệt, ta điều khiển ba reference theo đúng thứ tự: lưu tiếp theo, đổi mũi tên, rồi tiến lên.

Chiến thắng của bài này: đảo ngược singly linked list tại chỗ trong time O(n) và extra space O(1).

1. Bài toán

Trước10 → 20 → 30 → None
Sau30 → 20 → 10 → None

Ta không đổi các value. Ta đổi hướng của từng reference next.

2. Ba con trỏ

previous giữ phần đã đảo. current là node đang xử lý. next_node tạm giữ phần chưa xử lý.

def reverse(head):
    previous = None
    current = head

    while current:
        next_node = current.next
        current.next = previous
        previous = current
        current = next_node

    return previous
Dòng quan trọng nhất: phải lưu next_node = current.next trước khi chạy current.next = previous. Nếu không, ta mất reference dẫn đến phần list chưa duyệt.

4. Hiệu năng

Mỗi node được xử lý đúng một lần. Thuật toán chỉ giữ vài reference, không tạo list hoặc node mới theo kích thước đầu vào.

Time O(n) Extra space O(1)

5. Bài tập của bạn

Viết lại hàm reverse(head) mà không nhìn code mẫu. Sau đó dùng hàm to_list từ bài trước để kiểm tra:

head = Node(10, Node(20, Node(30)))
new_head = reverse(head)
print(to_list(new_head))  # [30, 20, 10]

Gửi code cho tôi và trả lời: nếu bỏ dòng next_node = current.next, phần list nào sẽ bị mất?

Ghi nhớ

Thứ tự cố định: save → reverse → advance. Lưu node kế tiếp, đảo liên kết hiện tại, rồi di chuyển hai con trỏ.
