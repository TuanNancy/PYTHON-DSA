Thay vì kiểm tra lần lượt, Binary Search nhìn phần tử giữa và loại bỏ một nửa vùng tìm kiếm sau mỗi lần so sánh.

Chiến thắng của bài này: tìm target trong sorted list bằng Binary Search với time O(log n).

1. Điều kiện bắt buộc

Binary Search chỉ quyết định được nên bỏ nửa trái hay nửa phải khi dữ liệu đã được sắp xếp.

numbers = [2, 4, 7, 10, 13, 18, 21]  # đã tăng dần

Nếu phần tử giữa nhỏ hơn target, mọi phần tử bên trái cũng nhỏ hơn target và có thể bị loại cùng lúc.

2. Ba vị trí điều khiển

left và right giới hạn vùng còn có thể chứa target. mid là vị trí giữa để so sánh.

def binary_search(numbers, target):
    left = 0
    right = len(numbers) - 1

    while left <= right:
        mid = (left + right) // 2

        if numbers[mid] == target:
            return mid
        if numbers[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
Vì sao mid + 1? Ta đã kiểm tra vị trí mid và biết nó không phải target, nên vùng tiếp theo không cần chứa lại mid.

4. Vì sao O(log n)?

Mỗi vòng lặp giảm vùng tìm kiếm còn khoảng một nửa: n → n/2 → n/4 → ... → 1. Số lần chia đôi là log₂(n).

Time O(log n) Space O(1)

5. Bài tập của bạn

Viết lại hàm binary_search(numbers, target) mà không nhìn code mẫu:

numbers = [1, 3, 5, 7, 9, 11]

print(binary_search(numbers, 7))  # 3
print(binary_search(numbers, 1))  # 0
print(binary_search(numbers, 8))  # -1
print(binary_search([], 5))       # -1

Gửi code cho tôi và trả lời: vì sao vòng lặp dùng left <= right thay vì left < right?

Ghi nhớ

Binary Search cần dữ liệu có thứ tự và một quy tắc giúp loại một nửa không gian tìm kiếm sau mỗi bước.
