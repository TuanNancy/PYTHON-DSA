16 phút · Two pointers

Fast & Slow
Pointers

Hai con trỏ chạy với tốc độ khác nhau có thể phát hiện Linked List quay lại node cũ mà không cần lưu toàn bộ node đã gặp.

Chiến thắng của bài này: dùng Floyd's cycle detection để phát hiện chu kỳ trong time O(n) và space O(1).

1. Chu kỳ là gì?

Linked List bình thường kết thúc tại None. Linked List có cycle khiến một node trỏ ngược về node đã đi qua:

1 → 2 → 3 → 4 ↑_______↓

Nếu chỉ dùng một con trỏ và chờ None, vòng lặp sẽ chạy mãi.

2. Một chậm, một nhanh

slow đi một node mỗi vòng. fast đi hai node. Có hai kết quả:

  1. Nếu không có cycle, fast hoặc fast.next sẽ thành None.
  2. Nếu có cycle, fast sẽ bắt kịp slow tại một node.
def has_cycle(head):
    slow = head
    fast = head

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next

        if slow is fast:
            return True

    return False
Dùng is: ta cần biết hai con trỏ có trỏ đến cùng một object Node, không chỉ là hai node có value giống nhau.

4. Hiệu năng

Các con trỏ đi qua số bước tỷ lệ với số node. Ta chỉ giữ hai reference, không dùng set chứa node đã gặp.

Time O(n) Space O(1)

5. Bài tập của bạn

Viết lại hàm has_cycle(head), sau đó tạo hai list để kiểm tra:

# Không cycle
plain = Node(1, Node(2, Node(3)))

# Có cycle: 1 → 2 → 3 → quay về 2
first = Node(1)
second = Node(2)
third = Node(3)
first.next = second
second.next = third
third.next = second

print(has_cycle(plain))  # False
print(has_cycle(first))  # True
