Linked list không đặt các phần tử cạnh nhau theo index. Mỗi node giữ dữ liệu và reference dẫn đến node tiếp theo.

Chiến thắng của bài này: tạo một singly linked list và duyệt từ head đến None.

1. Một node chứa gì?

Mỗi node cần hai thông tin:

  1. value: dữ liệu đang lưu.
  2. next: reference đến node kế tiếp, hoặc None nếu đây là node cuối.
class Node:
    def __init__(self, value, next_node=None):
        self.value = value
        self.next = next_node
10next→ 20next→ 30next→ None

head là reference đến node đầu tiên. Từ head, ta đi theo next để tới các node còn lại.

third = Node(30)
second = Node(20, third)
head = Node(10, second)

2. Duyệt bằng current

Linked list không có truy cập trực tiếp như items[2]. Muốn đến node thứ ba, ta phải bắt đầu ở head và đi qua từng next.

def to_list(head):
    values = []
    current = head

    while current:
        values.append(current.value)
        current = current.next

    return values
Điều kiện dừng: sau node cuối, current = current.next làm current trở thành None; vòng while current kết thúc.

4. List Python khác linked list

Kiểu list có sẵn của Python là dynamic array, hỗ trợ truy cập index trung bình O(1). Singly linked list truy cập theo vị trí là O(n), nhưng thêm hoặc xóa ở đầu có thể là O(1).
