Mỗi bài phải để lại một mô hình tư duy có thể tái sử dụng: dấu hiệu nhận dạng, invariant, lý do đúng và giới hạn của lời giải.

  1. Viết brute force trước khi tối ưu.
  2. Tự code 25–35 phút trước khi xem gợi ý.
  3. Bài B ôn sau 3 và 7 ngày.
  4. Bài C ôn sau 1, 3, 7 và 14 ngày.
  5. Chỉ gọi là mastery khi giải lại được.
75 bài đang hiển thị

Không có bài nào trong bộ lọc này.

01 / Trước khi code

Đọc để hiểu cấu trúc

  1. Viết lại input, output và constraint.
  2. Nêu brute force và complexity.
  3. Tìm dấu hiệu nhận dạng pattern.
  4. Xác định invariant.
02 / Trong khi code

Tự chiến đấu trước

  1. Tự code tối đa 35 phút.
  2. Xem gợi ý theo từng tầng nếu bí.
  3. Test edge cases bằng tay.
  4. Không chép code mà chưa hiểu.
03 / Sau khi code

Biến bài thành kiến thức

  1. Ghi dấu hiệu nhận dạng.
  2. Giải thích invariant và tính đúng.
  3. Ghi time/space complexity.
  4. Xếp loại A, B hoặc C.
Definition of done

Khi nào bạn thực sự hoàn thành?

  • 75 bài cốt lõi đã được giải.
  • Ít nhất 60 bài đạt A trong một lần giải lại.
  • Cả 25 pattern đạt tiêu chí mastery.
  • Đạt ít nhất 3/4 bài trong hai đề thi thử liên tiếp.
  • Mọi lời giải đều có complexity và lý do đúng.
